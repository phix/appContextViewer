# appContextViewer

Dependency and relationship graph viewer for hundreds of applications.

The spec is complete and lives in this repository: the glossary in [`CONTEXT.md`](CONTEXT.md), the decisions in [`docs/`](docs/) (architecture, performance budgets, validation surfacing, catalog sources, URL state, the Center, licensing, the ADRs), the producer contract in [`docs/schema-v1.md`](docs/schema-v1.md) and [`schema/`](schema/), and the fixtures in [`samples/`](samples/README.md). Planning ran as a wayfinder map, [issue #1](https://github.com/phix/appContextViewer/issues/1), now closed. The build is tracked in [Build the viewer v1: slice index](https://github.com/phix/appContextViewer/issues/30).
